Academic usage (from the review)

Paper protocolHow to run it here
Intra vs inter template (FATURA, DocILE)Fix Template variant for intra; randomise 1-50 for inter. Use Split: holdout layout to reserve an unseen layout cluster.
Clean vs faded vs bad-scan (Augraphy)Use Clean preset, mid Machine difficulty, and Scan preset as the three strata. Same labels, three renders.
Gold vs OCR enginesExport reading_order_text as gold transcript; run PaddleOCR / EasyOCR / Tesseract on printed scans and compare CER/WER.
Native vision vs OCR to markdown (2509.04469)Score the VLM on pixels directly, then on charges_markdown only. Expect the parsed pipeline to trail by 10-40pp on scans.
Abstention / NOT_FOUND (SCORE, RealDocBench)Keep Missing-field rate near 15%. Exported missing_fields are the must-abstain list; hallucinating them is penalised.
KILE + LIR boxes (DocILE)Export COCO / KILE after rendering at 100% zoom; boxes are measured from the live DOM in 0-1000 space.
Raster-only PDFs (no text leakage)Print / PDF is vector (selectable text). For OCR-faithful eval use Raster PDF (image-only pages, ~192 DPI) or Raster PNG (.zip) (one ZIP holding every sheet PNG, opens with a double-click on macOS/Windows). Under file://, logos render as monogram plates in raster; serve the folder over localhost for full logo fidelity. Alternatively, upload one or more logo files (Logo source = uploaded image(s)) — uploads are inlined as data, so raster keeps varying brand logos even under file://.
AI-agent bulk runsOpen with ?agent=1&seed=7&n=500&types=freight,retail,electric&split=auto to auto-generate (poll window.InvoiceLab.done), then pull InvoiceLab.pack() / InvoiceLab.card() / InvoiceLab.batch() via evaluate, or click Dataset pack for one card+records JSON. Only 24 sheets render no matter the batch size, so large-n runs stay fast.
Dataset cardThe Dataset card tab auto-builds classes (doc type, split, layout cluster, template variant) plus frequency charts (difficulty flags, missing fields, items/doc, totals, rotation) from the current batch. Download as .md / .json, or bundled in the pack.
Downloads won't open / misnamedAll exports are generated locally as Blobs. In Chrome/Edge a Save dialog asks where to put each file (real files, real names — nothing stays a blob). Other browsers auto-download to the default folder. If Safari saves a file as "Unknown" with no extension (so it won't open), retry from the Download center under the Preview tab: text files have a Copy button (paste into an editor and save), images open in a tab for right-click saving, and an "Unknown" bundle only needs renaming to .zip. The PNG burst is bundled into one .zip so browsers never block it as "multiple automatic downloads".
